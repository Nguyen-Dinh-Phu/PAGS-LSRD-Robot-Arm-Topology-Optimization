# Pre-publication review checklist

- [ ] Upload the authors' **final** `MAIN.m`, `PAGS_Study.m`, `PAGS_LSRD.m`, `PAGS_Output.m`, and the full `FUNCTION_PAGS` directory.
- [ ] Check function names, filenames and `addpath` for case-sensitive platforms.
- [ ] Validate the Q4 local node / DOF ordering and element index mapping.
- [ ] Confirm the applied resultant load is −5000 N for the manuscript robot-arm case.
- [ ] Record and reconcile the chosen `G12` and `Emin` against the manuscript.
- [ ] Test `history` and `sweep` with the intended 360 × 90 mesh.
- [ ] Compare generated figures and quantitative Table 3 metrics to the original study.
- [ ] Add a suitable software license **only after author agreement**.
- [ ] Add journal citation metadata when the manuscript citation is finalized.
- [ ] Confirm that source-code public release is approved by all relevant authors.

> This checklist tracks pending work; checked validation must be based on actual executed tests, not code inspection alone.
